# 앵커 (Anchor) · 시연판

건강·성장·관계·회복·재정, 내가 정한 다섯 영역을 하루 끝에 1분 체크하고, 쌓인 기록을 주간 패턴 리포트로 보는 모바일 웹앱입니다.

## 실행

- **배포 주소**: 배포 뒤 Vercel 프로젝트 화면의 Domains 주소를 여기에 적습니다.
- **내려받아 실행**: 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다. 설치나 빌드가 필요 없습니다.

## 재현 경로 3단계

1. 첫 화면에서 **샘플로 둘러보기 › 도토리**를 고릅니다.
2. 오늘 체크에서 항목 몇 개를 누른 뒤 **하루 마무리하기** → 컨디션을 고르고 **저장하고 마무리**를 누릅니다. 노을 완료 화면이 뜨고 2초 뒤 돌아옵니다.
3. 아래 **리포트** 탭에서 지난주 리포트를 보고, **‹**를 눌러 2주 전(사흘 비었던 주)으로 갑니다.

구름 샘플로 들어가면 안전 카드를, 첫 화면에서 직무를 고르고 **다음**을 누르면 나다움 설계를 볼 수 있습니다.

## 지키는 원칙

- 정적 웹앱입니다. 로그인, 서버, 데이터베이스가 없습니다.
- 외부 주소를 호출하지 않습니다. 글꼴도 같은 주소의 `fonts/`에서 불러옵니다.
- 프레임워크 없이 HTML과 바닐라 JS로 만들었습니다.
- 기록은 각자의 브라우저에만 저장됩니다. 여러 사람이 동시에 열어도 서로의 기록이 섞이지 않습니다.
- API 키, 개인정보가 없습니다. 샘플의 이름·숫자·메모는 모두 가상 데이터입니다.
- 리포트 문장은 미리 써 둔 샘플 문장입니다. 앱 안에서 AI를 호출하지 않습니다.

## 제약 · 미구현

- 리포트의 문장(요약, 패턴, 실험)은 도토리 샘플에만 있습니다. 직접 설정한 기록의 리포트에는 차트와 안내 문구만 나옵니다.
- 기기를 바꾸거나 브라우저 기록을 지우면 내 기록이 사라집니다. **⋯ › 내 기록 내보내기 (CSV)**로 파일로 받을 수 있습니다.
- 알림, 월간·연간 리포트, 문항 직접 추가, 실험 타이머, 홈 화면 설치는 이번 시연판에 없습니다.
- 일요일에 열면 지난주의 주간 항목이 아직 입력 전이어서, 도토리 리포트의 숫자가 문장과 조금 다릅니다.

## 폴더

| 위치 | 내용 |
| --- | --- |
| `index.html` | 첫 화면이자 앱 전체. `build.js`가 만든 파일입니다 |
| `sw.js`, `fonts/` | 한 번 연 뒤 연결 없이도 열리게 하는 파일, Pretendard 글꼴 |
| `src/` | 고치는 곳. `style.css`(디자인 토큰과 스타일), `app.js`(화면과 계산), `index.tpl.html`(껍데기) |
| `data/anchor_demo_data.json` | 문항 53개, 추천 순서, 샘플 3명, 미리 쓴 리포트 |
| `test.js`, `tools/check_spec.js` | 자동 점검, 기획안 기능 점검 |
| `docs/checklist_v2.0.md` | 기능 점검표 |

## 고칠 때

`index.html`을 직접 고치지 않습니다. `src/`나 `data/`를 고친 뒤 아래를 돌리고, 바뀐 `index.html`을 함께 올립니다.

```
node build.js        index.html 다시 만들기 (설치 없이 돕니다)
npm install          처음 한 번 (자동 점검용)
npm test             다시 만든 뒤 자동 점검
```

Vercel은 빌드를 하지 않고 `index.html`, `sw.js`, `fonts/`만 그대로 내보냅니다(`.vercelignore`).
